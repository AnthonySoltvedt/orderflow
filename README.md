# OrderFlow

A full-stack order management application built using Python, FastAPI, PostgreSQL and React.

## Overview

OrderFlow is a personal software development project designed to explore how businesses can manage orders more efficiently through software and automation.

The project includes a REST API, database integration, a React frontend and scripts for processing sample WooCommerce orders.

## Technologies

- Python
- FastAPI
- PostgreSQL
- React and JavaScript
- REST APIs
- Git and GitHub

## Features

- Create and retrieve orders
- Update order statuses
- Delete orders
- Store order information in PostgreSQL
- Process sample WooCommerce order data
- Prevent duplicate orders during processing
- React-based frontend
